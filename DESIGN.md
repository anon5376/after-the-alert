# After the alert

A small, useful public reference site. The reader comes with an incident name or an unresolved operational question; the interface gets them to the guide, source or local tool quickly.

## Visual decisions

- Read mode. Direct title and brief description, then three practical tool links, then the searchable incident library.
- Warm offwhite page (#f5f5f2), white reading surfaces, dark ink (#202320), quiet secondary text (#5b625e), and blue links (#284fc4).
- Inter throughout. Medium weight for titles and labels; regular body text. Code and identifiers alone use monospace.
- One 1080px content column with 32px desktop and 16px mobile outer gutters. Fine dividers and proximity organize content. Corners are 8px on controls and 12px on substantial surfaces.
- Desktop incident entries align name, evidence summary and useful links. Phones stack each entry and expose links as a compact touch-friendly row.
- Guides and manual use a contents column beside a white reading surface; mobile contents come first.
- Search and topic controls use native inputs and buttons. Copy confirms in place. No decorative motion, illustrations, accounts or dark mode.
- Donations follow all free resources. The supplied Base address and network remain explicit.

The site uses plain HTML, CSS and JavaScript with no application dependencies.
