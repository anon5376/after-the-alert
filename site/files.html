Website files

The website is plain HTML, CSS and JavaScript. There is no backend, database, account system, payment processor or application dependency. Everything under site/ is deployed as static content, except _headers, which configures hosting headers.

Downloadable scripts

File under site/downloads/What it does
check-php-version.mjsNode.js command-line tool comparing a supplied PHP version with the snapshot's fix floors. Does not scan a server or run PHP.
inspect-dependency-files.mjsNode.js tool reading selected requirements, lockfiles, Dockerfiles and Compose files for LiteLLM declarations. Does not import projects, run Python or use the network.
inspect-litellm-metadata.shBash tool checking immediate entry names in a supplied offline site-packages directory. Does not read file contents or start Python/pip; rejects symlink paths.

All three are read-only checks. Read their source and help before running them. A declaration, an installed artifact and execution evidence are different findings; none of these scripts certifies a system as safe.
