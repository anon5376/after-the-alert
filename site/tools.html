Use the offline scripts

Inspect the downloaded source first. Run the Node tools on a trusted machine. For suspected compromised environments, analyze a read-only copy; do not run the affected application to collect evidence.

Inspect dependency declarations

Download inspect-dependency-files.mjs. Supply only selected text files; the tool does not search your machine. Inputs are capped at 2 MiB per file. Output uses input numbers and sanitized matches, not file contents.

node inspect-dependency-files.mjs --json -- requirements.txt uv.lock Dockerfile

The parser covers common declaration forms, not every TOML/YAML feature. REVIEW is a static match, never proof of installation or execution. UNKNOWN means the file or syntax could not be assessed. Exit 0 means processing completed; exit 2 includes rejected or unassessed inputs.

Inspect installed metadata without Python

Download inspect-litellm-metadata.sh. Pass a physical path to an offline copy’s site-packages directory. It checks immediate entries only and rejects symlink paths.

bash inspect-litellm-metadata.sh /physical/path/to/site-packages

Generic filenames need review. Missing markers do not clear historical exposure. Neither Python nor pip is invoked.

Compare a PHP version locally

Download check-php-version.mjs. This compares the string you supply; it does not discover your production runtime.

node check-php-version.mjs 8.3.35
